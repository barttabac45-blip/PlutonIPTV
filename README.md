# 🪐 PlutonIPTV

Lecteur IPTV pour Android TV, Fire TV, tablettes et téléphones.

## Installer

**Lien direct (toujours la dernière version) :**
https://github.com/barttabac45-blip/PlutonIPTV/releases/latest/download/PlutonIPTV.apk

### Sur Android TV / Fire TV avec l'application Downloader
1. Installe **Downloader** (AFTVnews) depuis le Play Store / l'Amazon Appstore.
2. Autorise Downloader à installer des applications inconnues.
3. Ouvre Downloader et tape le code ou le lien ci-dessus, puis installe.

### Mise à jour
Télécharge et installe la nouvelle version par-dessus : tes réglages et favoris sont conservés.

## Première connexion
Connecte-toi avec ton compte Google. Si ta liste de lecture n'est pas encore configurée,
l'appli l'attend et s'ouvre toute seule dès qu'elle est prête.
